# Vintage Car Exhibition Flyer Design 🚘

## Project Overview
This project showcases a sample promotional flyer designed for a Vintage Car Exhibition. The design combines a retro aesthetic with classic automobile imagery, bold typography, and vintage-inspired colors.

## 🎨 Design Highlights
- Vintage and retro-inspired layout
- Classic car illustrations and photography
- Bold typography with a distressed texture
- Warm beige, burgundy, and navy blue color palette
- Event information presented in a clear layout
- Decorative badges, icons, and borders
- Call-to-action section with a QR code

## 🛠️ Tools & Skills
- Graphic Design
- Flyer Design
- Typography
- Color Theory
- Layout and Composition
- Visual Communication

## 🎯 Purpose
Created as a sample graphic design portfolio project to demonstrate flyer design skills for automotive exhibitions, promotional events, and vintage-themed campaigns.
